# Style Profiles

마음에 든 화풍/프롬프트를 저장하는 폴더입니다. 새 화풍은 `<name>.json`으로 추가합니다.

| 파일 | 설명 |
|---|---|
| fantasy_jewel_samurai.json | 홀로그램 보석 갑옷 사무라이 여전사 |
| neon_cyberpunk_club_poster.json | 사이버펑크 네온 클럽 포스터 (LOVE LEVEL) |

## 사용 순서
1. 원하는 화풍 JSON의 `base_prompt` 사용
2. 가능하면 원본을 참조 이미지로 쓰는 i2i 편집 모델
3. 6분할 시트로 시안 선택 -> 고른 번호만 단일 컷 고품질 재생성
