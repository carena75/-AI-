# 이어받기·기록 (토큰 최소)

## 읽기 (세션 시작)
- `CLAUDE.md`가 `HANDOFF.md`를 자동으로 불러온다. 이미 컨텍스트에 있으면 다시 읽지 않는다.
- `docs/history/`와 큰 파일은 사용자가 과거 상세를 물을 때만 연다.
- 결과 영상·이미지는 HANDOFF의 `job_key`로 `abocado_get_job_status`를 불러 URL을 복구한다. 다시 생성하지 않는다.

## 쓰기 (이 시점마다, 길게 쓰지 않는다)
1. 유료 생성을 제출한 직후: 무엇을, 모델·길이·해상도·오디오, `job_key`, 차감 크레딧 (1~3줄)
2. 사용자가 단계를 승인한 직후: 승인된 구성 한 줄
3. 작업을 마치거나 세션을 끝낼 때: "지금 상태" 갱신 + 다음 할 일 1~3줄
- HANDOFF.md는 **40줄 이내**. 넘으면 오래된 항목을 `docs/history/<날짜>-<주제>.md`로 옮기고 요약만 남긴다.
- 장문 프롬프트, 응답 원문, 대화 내용은 적지 않는다. 비밀키·토큰·개인정보는 절대 적지 않는다.

## 저장 (필수)
클라우드 세션의 디스크는 임시라서 **커밋·푸시하지 않으면 다음 세션에 남지 않는다.** 기록을 갱신하면 지정된 작업 브랜치에 커밋하고 푸시한다. 공개 저장소이므로 올리기 전에 민감한 내용이 없는지 확인한다.

## 한계 (사용자에게 솔직히)
- 이전 대화 전체를 기억하는 것이 아니라 HANDOFF에 적힌 요약만 이어받는다. 적히지 않은 내용은 모른다.
- PC의 Claude Code나 claude-mem 기억과는 별개다.
