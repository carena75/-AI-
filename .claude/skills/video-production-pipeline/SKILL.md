# 영상 제작 파이프라인 (저비용 6단계)

시작 전 HANDOFF.md의 현재 상태를 확인한다(이어받기 규칙은 `handoff-memory`). 모든 유료 호출 전에 `abocado_check_cost`를 **실제 생성과 같은 options 전부**(duration, resolution, aspect_ratio, generate_audio)로 먼저 낸다. 가격표·모델은 `references/cost-and-models.md`, 양식은 `references/templates.md`(필요한 단계에서만 연다).

## 단계 (각 단계 끝에 사용자 승인 1회, 질문은 한 번에 묶어서)
0. **의도 확인** — 용도, 길이, 화면비, 오디오 여부, 예산 상한. 안 정한 값은 기본값(12초, 16:9, 480p)으로 제안한다.
1. **기획 브리프 (무료, 텍스트)** — 컨셉 1줄, 컷 구성(컷당 4초 단위), 톤·색, 사운드. 승인 전에는 생성하지 않는다.
2. **그리드 스토리보드 1장 (이미지 1회)** — 컷별 패널과 라벨을 한 장에 담는다. 낱장 프레임 여러 장 금지. 컨셉 확인용이며 영상 시작 프레임으로 쓰지 않는다(그리드가 영상에 들어간다).
3. **480p 무음 테스트** — 가장 위험한 컷 하나만 4초로 먼저 만든다. 통과해야 다음으로 간다.
4. **최종 생성** — 승인된 구성을 **전체 길이 1회**로 생성한다. 컷별로 따로 만들어 이어붙이지 않는다. 오디오는 최종에서만 켠다.
5. **최종 확인** — 영상 URL, 설정, 차감액을 보고한다. 확인 가능한 것과 아닌 것을 구분해서 적는다.
   - 가능: 생성 성공 여부, 길이·해상도 설정, 크레딧 일치, (이미지는 `abocado_view_image`로) 스토리보드 구성
   - 불가·미확인: 영상 화면과 소리(다운로드가 막혀 있다). 사용자가 직접 재생해 확인하도록 안내하고 "시각·청각 검수 미확인"이라고 쓴다
   - 사용자 확인 후 불합격이면 문제 장면만 짧게 다시(테스트 단가로) 만든다

## 기록 (잊으면 다음 세션이 이어받지 못한다)
유료 호출을 제출할 때마다 HANDOFF.md에 `job_key`, 설정, 차감액을 1~3줄로 적고 커밋·푸시한다.

## 비용·토큰 규칙
- 견적과 실차감이 다르면 숨기지 말고 보고한다. 오디오를 켜면 영상 가격이 약 2배다.
- 제출 후에는 기다리며 턴을 잡지 않는다. "백그라운드 생성 중"이라고 알리고, 결과가 필요할 때만 `abocado_wait_for_job`을 짧게(≤50초) 쓴다.
- 작업이 예상 시간의 3배를 넘기면 상태를 1회 확인하고 알린다. 재생성은 추가 차감이라 허락 없이 반복하지 않는다.
- 긴 도구 결과는 필요한 필드만 인용한다. 같은 설명을 되풀이하지 않는다.
- 프로젝트가 끝나면 새 세션에서 시작한다. 이어갈 정보는 HANDOFF가 담는다.

## 하지 않는 것
- 타인의 브랜드·실존 인물 얼굴·캐릭터 도용, 확인되지 않은 효능·수치 표기.
- 확인 없이 고가 모델(Seedance 2.x)로 올리기. 기본은 Seedance 1.5.
