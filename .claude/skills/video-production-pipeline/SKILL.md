# 영상 제작 파이프라인 (저비용 5단계)

모든 유료 호출 전에 `abocado_check_cost`를 **실제 생성과 같은 options 전부**(duration, resolution, aspect_ratio, generate_audio)로 먼저 낸다. 가격표·모델은 `references/cost-and-models.md`, 양식은 `references/templates.md` (필요한 단계에서만 연다).

## 단계 (각 단계 끝에 사용자 승인 1회, 질문은 한 번에 묶어서)
0. **의도 확인** — 용도, 길이, 화면비, 오디오 여부, 예산 상한. 안 정해진 값은 기본값(12초, 16:9, 480p)으로 제안하고 넘어간다.
1. **기획 브리프 (무료, 텍스트)** — 컨셉 1줄, 컷 구성(컷당 4초 단위), 톤·색, 사운드. 사용자 OK 전에는 생성하지 않는다.
2. **그리드 스토리보드 1장 (이미지 1회)** — 컷별 패널과 라벨을 이미지 한 장에 담는다. 낱장 프레임 여러 장 생성 금지. 이 그림은 컨셉 확인용이며 영상의 시작 프레임으로 쓰지 않는다(그리드가 영상에 들어간다).
3. **480p 무음 테스트** — 가장 위험한 컷 하나만 4초로 먼저 만든다. 통과해야 4단계로 간다.
4. **최종 생성** — 승인된 구성을 **한 번에**(전체 길이 1회) 생성한다. 컷별로 따로 만들어 이어붙이지 않는다. 오디오는 최종에서만 켠다.
5. **기록** — `HANDOFF.md`에 결과 링크, 사용한 설정, 차감 크레딧, 검수 상태를 적는다.

## 비용·토큰 규칙
- 견적과 실차감이 다르면 숨기지 말고 보고한다. 오디오 켜면 영상 가격이 약 2배다.
- 제출 후에는 기다리며 턴을 잡지 않는다. "백그라운드 생성 중"이라고 알리고, 결과가 필요할 때 `abocado_wait_for_job`을 짧게(≤50초) 쓴다.
- 작업이 예상 시간의 3배를 넘기면 상태를 1회 확인하고 사용자에게 알린다. 재생성은 추가 차감이라 허락 없이 반복하지 않는다.
- 결과는 가능한 한 직접 본다(`abocado_view_image` 등). 못 봤으면 "시각 검수 미확인"이라고 쓴다. 소리는 이 환경에서 검수할 수 없다고 명시한다.
- 같은 내용을 되풀이해 설명하지 않는다. 긴 도구 결과는 필요한 필드만 인용한다.
- 프로젝트가 끝나면 새 세션에서 시작한다(긴 대화 = 매 턴 입력 증가). 이어갈 정보는 `HANDOFF.md`가 담는다.

## 하지 않는 것
- 타인의 브랜드·실존 인물 얼굴·캐릭터 도용, 확인되지 않은 효능·수치 표기.
- 확인 없이 고가 모델(Seedance 2.x)로 올리기. 기본은 Seedance 1.5.
