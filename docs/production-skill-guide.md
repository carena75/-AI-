# 제작 스킬 적용 가이드 (기획 → 이미지 → 영상 → 썸네일 → 업로더 패키지)

작성일 2026-10-02. 근거: 전역 `~/.claude/CLAUDE.md` 라우팅 표 + 훅 `~/.claude/hooks/route-production.js`.

> **이 저장소의 상태**: 이 파일은 스킬 **목록과 사용 규칙(색인)** 입니다. 각 스킬의 본문(`SKILL.md`)과 훅 파일은 이 저장소에 없으며,
> 사용자의 PC(`~/.claude`)에 있습니다. 클라우드 세션에서는 본문이 로드되지 않으므로, 아래 스킬을 실제로 쓰려면 본문 파일을
> `.claude/skills/<이름>/SKILL.md`로 이 저장소에 추가해야 합니다.

> 문서별 저장 위치와 제외 내역은 `docs/skill-ledger.md` 참고.

## 자동 적용 구조 (3겹)

| 층 | 무엇이 | 자동 정도 |
|---|---|---|
| 1 | 전역 CLAUDE.md 라우팅 표·생성 전 규칙 | 매 세션 자동 로드 |
| 2 | UserPromptSubmit 훅 | 제작 동사(만들·제작·생성·뽑아·짜줘 등)+키워드 매칭 시 규칙 주입 (2,500자 초과·/명령은 제외) |
| 3 | 스킬 본문·레퍼런스 | 주 스킬 1개만 먼저 로드, 레퍼런스는 해당 단계에서만 열림 |

자동이 아닌 것: 크레딧 차감 승인(견적→승인은 항상 사용자), 나노바나나 실생성(프롬프트 텍스트만 제공).

## 공통 규칙 (모든 스킬보다 우선)

- 이미지 = **그리드 스토리보드 한 장** (개별 장 생성 금지, 개별 납품 스틸 명시 요청 시만 예외)
- GPT 이미지 2/2.5 = 아보카도 실생성 / 나노바나나 = 프롬프트만 (플로우 구독)
- 영상 = 샷별 스토리보드 + 나레이션 승인 후 애니메이션. 모델 기본 **시댄스 1.5** (480p 테스트 → 최대 720p). v2 reference는 명시 요청 시만
- 생성 전: `abocado_list_models` → `abocado_check_cost`(화면비·오디오 등 options 전부 포함) → 승인
- 결과는 실제로 보고 검수 (못 봤으면 "시각 검수 미확인")
- 그리드 이미지는 컨셉 스케치 용도. 글자가 들어가는 실납품(상세페이지 등)은 Hallmark HTML
